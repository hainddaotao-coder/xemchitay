# Landing page Xem chỉ tay – Tử Vi Chi Đạo

## Chạy cục bộ

```bash
npm install
npm run dev
```

Mở `http://localhost:3000`; trang gốc sẽ chuyển đến `/landing.html`.

## Build

```bash
npm run build
npm start
```

Google Form chính thức được nhúng trực tiếp và có liên kết dự phòng mở trong cửa sổ mới.
